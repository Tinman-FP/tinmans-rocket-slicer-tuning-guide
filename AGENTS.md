# Rocket guide working rules

- This is documentation and a reusable test-file project, not Tinman development.
- Do not modify the original guide, shared slicers, profiles or either printer.
- Pin installed Rocket version and distinguish later-release documentation.
- Inventory controls/options before claiming exhaustive coverage; never invent defaults.
- Explain fields in original plain language; cite functional evidence and limitations.
- Do not transfer old-machine tuning or Tinman E/V/tool assumptions to a new unit.
- Public files must exclude endpoints, identities, accounts, credentials and raw backups.
- Test states are prepared, Rocket-checked, printed, validated or superseded; never
  promote one state to another without evidence. No live print is authorized by a file.
- Publish test files only after Rocket format/routing/privacy checks, preserve licenses,
  and link the verified public release in the guide. Do not publish generic runnable G-code.
