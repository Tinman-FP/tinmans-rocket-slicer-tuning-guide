# Test geometry plan

The approved starting point is the existing calibration geometry used by Tinman
and Tinmans Tuning Guide. Reuse the actual models where their license permits;
preserve provenance, original source, attribution and any redistribution terms.

Rocket must perform the slicing. Verify imported scale, orientation and feature
geometry, then establish the required variable schedule through controls actually
supported by the installed Rocket version. A Tinman 3MF import is not evidence
that its calibration modifiers survive, and a model is not a variable G-code test.

Record any unsupported or incompatible test before proposing a replacement.
Do not silently substitute a new model or claim an unsupported PA stage passed.

The four original simple coupons were prepared before this correction.
They are superseded custom prototypes for this plan, not the agreed Tinman test
geometry, and none has been printed or published. One imported into Rocket; no
completed slice or parameter schedule was verified. Keep them as development
history rather than presenting them as the community test pack. Their local archive
is excluded from this repository.

The first reusable pack now contains the 19 original flow-tile meshes with pinned
sources, separate licenses and a one-tile/one-multiplier Rocket recipe. All meshes
pass conversion checks; a representative zero tile has a native import/slice and
1.00-versus-0.90 deposition comparison. Other tiles have not been individually
native-sliced, and none has physical validation in this pack.

After actual Rocket checks, publish the qualified reusable files and recipes on
GitHub and link the real versioned release from the guide. Label import/slice,
physical print and material-profile validation separately. Do not publish private
account projects or universal ready-to-run machine G-code.
