Changes on October 19 2026

William Tinney's Rocket guide project, with Codex by OpenAI, extracted each of the 19 source objects as a separate binary STL. Every source triangle is retained. Each tile is translated to the origin; there is no resizing, remeshing, smoothing, decimation or relabeling. Binary STL stores float32 coordinates. The conversion source is extract_tinman_flow_models.py, licensed under AGPL-3.0 for this conversion and its generated derivatives. The manifest records each original object, dimensions, triangle count and hash.

To rebuild from the included sources, use Python 3.10 or newer from the repository root: python3 scripts/extract_tinman_flow_models.py. No slicer or network is needed.

STL does not carry units, material settings or calibration modifiers. Import as millimeters and verify 40 × 30 × 2 mm before slicing. Numbers on the tiles are geometry, not instructions executed by Rocket. Use the accompanying recipe.
